**📈 【财务管理】核心公式**

### 一、资本成本计算

|公式类型|公式|
| -----------------------------| ----------------------------------------|
|债务资本成本 Kd|年利息×(1-T) / 筹资总额×(1-筹资费率)|
|股权资本成本 Ke（CAPM）|Rf + β×(Rm-Rf)|
|股权资本成本 Ke（股利增长）|D₁/P₀ + g|
|WACC|(债务比例×Kd) + (股权比例×Ke)|

### 二、杠杆效应

```
DOL（经营杠杆系数） = 边际贡献 / EBIT
DFL（财务杠杆系数） = EBIT / (EBIT - I)
DTL（总杠杆系数） = DOL × DFL
```

### 三、投资决策

```
NPV = ∑(各期净现金流量/(1+k)ⁿ) - 初始投资
IRR = NPV=0时的折现率
回收期 = 累计现金流首次转正的时间
```

### 四、本量利分析

```
盈亏平衡点销量 = 固定成本 / (单价 - 单位变动成本)
安全边际 = 实际销量 - 盈亏平衡点销量
目标利润销量 = (固定成本 + 目标利润) / 单位边际贡献
```

### 实务题

**1.**  甲公司2025年1月1日以银行存款5000万元取得乙公司30%股权，当日乙公司可辨认净资产公允价值为18000万元。甲公司采用权益法核算。2025年乙公司实现净利润2000万元，宣告分配现金股利800万元。假设无其他调整事项，则2025年末甲公司长期股权投资账面价值为多少？

<details>  
<summary>点击查看答案</summary>

**答案：**   
初始确认：支付5000万 vs. 应享有18000×30%=5400万，差额400万计入营业外收入  
所以初始账面 = 5400万

年末调整：+2000×30%=600万，-800×30%=240万

期末账面价值 = 5400 + 600 - 240 = 5760万元  
</details>

### 财管题

**2.**  某公司普通股β系数为1.5，无风险利率5%，市场平均收益率12%。使用CAPM模型计算该普通股的资本成本。

<details>  
<summary>点击查看答案</summary>

**答案：**   
Ke = Rf + β(Rm - Rf) = 5% + 1.5×(12%-5%) = 5% + 10.5% = 15.5%  
</details>

### 经济法题

**3.**  下列关于有限责任公司股东会特别决议事项的说法中，正确的是？  
A. 修改公司章程需经出席会议的股东所持表决权过半数通过  
B. 增加注册资本需经代表2/3以上表决权的股东通过  
C. 公司合并需经代表1/2以上表决权的股东通过  
D. 发行债券需经全体股东一致同意

<details>  
<summary>点击查看答案</summary>

**答案：B**  
特别决议事项（2/3以上表决权通过）：章程修改、增减资本、合并分立解散变更。  
A错，不是"出席会议"，而是"代表2/3以上表决权"。C错，应是2/3以上。D错，发行债券属于一般决议或董事会职权。  
</details>

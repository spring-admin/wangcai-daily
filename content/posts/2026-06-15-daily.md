**二、中级实务**

### 1️⃣ 三分类标准（依据业务模式+合同现金流量特征）

|分类|业务模式|合同现金流量特征|
| -----------------------| ------------------| --------------------------|
|① 摊余成本计量|收取合同现金流量|仅本金+利息偿付（SPPI）|
|② FVTOCI（债务工具）|收取+出售|SPPI|
|③ FVTPL（兜底类）|其他|不符合SPPI或业务模式不符|

### 2️⃣ 初始与后续计量

- **初始计量**：均按公允价值计量

  - ①摊余成本：交易费用计入初始确认金额
  - ②FVTOCI：交易费用计入初始确认金额
  - ③FVTPL：交易费用计入当期损益
- **后续计量**：

  - ①摊余成本法：按实际利率计算利息收入
  - ②FVTOCI债务工具：公允价值变动计入OCI，减值计提，处置时OCI转入损益
  - ③FVTPL：公允价值变动计入当期损益

### 3️⃣ 预期信用损失减值模型

适用范围：①摊余成本、②FVTOCI债务工具、租赁应收款等

- 三阶段法：

  - 阶段1：信用风险未显著增加 → 确认未来12个月预期信用损失
  - 阶段2：信用风险显著增加 → 确认存续期预期信用损失
  - 阶段3：已发生信用减值 → 确认存续期预期信用损失，利息收入按摊余成本计算

**四、财管**

### 1️⃣ 净现值（NPV）

```
NPV = Σ CFt / (1 + r)^t - 初始投资额
```

判断：NPV > 0 → 可行；NPV < 0 → 不可行

### 2️⃣ 资本资产定价模型（CAPM）

```
Ri = Rf + β × (Rm - Rf)
```

- Ri：必要收益率
- Rf：无风险利率
- β：系统性风险系数
- Rm - Rf：市场风险溢价

### 3️⃣ 加权平均资本成本（WACC）

```
WACC = E/V × Re + D/V × Rd × (1 - T)
```

### 4️⃣ 可比公司法

```
β资产 = β权益 / [1 + (1-T) × (负债/权益)]
β权益 = β资产 × [1 + (1-T) × (负债/权益)]
```
